# Changelog

## 0.1.0 — 2026-09-28 (prerelease)

- Native local music library, conservative metadata handling, artwork, fuzzy search, playlists, likes, local mixes, and lyrics.
- Background Media3 playback, persistent queue, shuffle/repeat, speed, sleep timer, and named best-part loops for songs and playlists.
- Discovery, durable downloads, and Android shared-link imports for supported public Spotify and YouTube items or direct audio URLs.
- Local metadata edits, M3U export, and versioned JSON backup/restore.
- 39 local automated tests and 3 Android 15 instrumentation tests passed; lint reported 0 errors and 33 warnings. See docs/TESTING.md for the exact checks and device-testing limits.

This is an initial evaluation release. It does not include every Spotify/YouTube Music feature, acoustic fingerprint recognition, or measured device battery/RAM guarantees. Read docs/FEATURES.md before relying on a particular workflow.
