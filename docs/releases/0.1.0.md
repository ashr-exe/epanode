Epanode 0.1.0 is an **evaluation prerelease** for Android 10 and newer.

### Included

- Local music scanning, artwork and metadata editing, fuzzy search, playlists, likes, deterministic local mixes, and lyrics.
- Background playback, queue controls, shuffle/repeat, speed, sleep timer, and system media controls.
- Named **best parts** with precise boundaries; loop a single part or the saved parts across a playlist.
- Discovery/downloads and Android share imports for supported public Spotify/YouTube items and direct audio links. Spotify links supply metadata; audio is matched from the search provider.
- M3U export and local JSON backup/restore.

### Install

Download `Epanode-0.1.0.apk` below, open it on Android, and allow installation from that source. In Epanode, choose **Find my music** and grant audio access. Add a folder in Settings if needed. No account or server is required for local playback.

### Verification and limits

**39 local automated tests and all 3 Android 15 emulator instrumentation tests passed. Android lint: 0 errors, 33 warnings. GitHub Android CI and CodeQL passed.** Framework/UI tests covered APIs 29 and 35. Two live checks covered music search/audio URL access and public Spotify track metadata. The APK signature and archive integrity were verified; APK size is 5.94 MiB.

This release does **not** implement every Spotify/YouTube Music feature. There is no acoustic fingerprint identification for untagged files with opaque names. Provider imports are not guaranteed for every link or playlist. Physical-device playback, Bluetooth, interruptions, battery, and RAM measurements remain pending. Read the repository's `docs/FEATURES.md` and `docs/TESTING.md` for exact coverage.

The APK is an optimized build signed with a **development certificate**. It is an evaluation build, not a Play Store or production signing identity. A future signing-key change may require backup and reinstallation.
